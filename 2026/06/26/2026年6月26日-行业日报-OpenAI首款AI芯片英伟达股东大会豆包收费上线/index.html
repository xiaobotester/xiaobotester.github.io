2026年6月26日-行业日报-OpenAI首款AI芯片英伟达股东大会豆包收费上线

摘要: 今日焦点：OpenAI发布首款自研AI推理芯片Jalapeno，九个月完成流片刷新行业纪录；英伟达股东大会黄仁勋宣告智能体时代到来；字节跳动豆包正式上线专业版收费；高通39亿美元收购Modular进军AI数据中心。

一、软件测试与质量保障

行业动态

6月25-26日未见软件测试领域重大工具更新或漏洞通报。近期测试工具迭代集中于AI辅助用例生成、自动化框架升级等方向：

  • Claude Code v2.1.193 发布：新增 autoMode.classifyAllShell 设置、实时文件路径自动补全、空闲后台 shell 命令自动内存压力回收等功能
  • GitHub Copilot Agentic Harness 跨模型评估：官方发布在20+模型间的性能与效率基准评测，为 AI 辅助编码工具选型提供统一标准
  • Codex 在 ChatGPT 移动端可用：新增一对一设备配对、通知、目标管理、文件预览等功能

来源：Claude Code v2.1.193 Release Notes

来源：GitHub Copilot Agentic Harness 评测

来源：Codex in ChatGPT Mobile App

来源：测试深度洞察 ｜ 2026年6月

技术趋势

2026年测试工具选型核心问题已超越 “Selenium还是Playwright”，更关键的是用例能否快速创建、页面变化后能否低成本维护。AI辅助测试用例生成和质量数据分析能力正成为测试工程师必备技能。当代码生成越来越自动化后，测试重心正从功能验证转向系统可靠性验证和边界场景覆盖。

来源：Claude Code / GitHub Copilot / Codex 移动端

二、AI与模型厂商

2.1 OpenAI发布首款自研AI推理芯片”Jalapeno”

北京时间6月25日，OpenAI正式对外发布首款自研AI推理芯片Jalapeno，由OpenAI与博通（Broadcom）联合开发，专为大语言模型推理场景设计。

核心亮点

  • 九个月完成流片：从设计到制造流片仅用9个月，传统高性能芯片设计周期通常需2-3年
  • AI辅助造芯：ChatGPT在芯片设计过程中发挥辅助作用，加速工程迭代与验证
  • 专注推理而非训练：推理是每日数亿用户持续产生的成本大头，压降30%-50%推理成本可节省天文数字
  • 性能表现：Jalapeño每瓦性能明显优于当前同类产品，可与英伟达Blackwell系列及谷歌TPU媲美
  • 部署计划：预计2026年底前完成部署，定位为”多代计算平台的第一步”

OpenAI宣言：”我们正在设计芯片架构、内核、内存系统、网络、调度——贯穿整个技术栈，每一层都围绕同一个目标优化：让我们的模型对用户更快、更稳定、更实惠。”

来源：OpenAI发布首款自研AI芯片

2.2 英伟达股东大会：黄仁勋宣告智能体时代

北京时间6月25日凌晨，英伟达年度股东大会释放多个信号：

  • 智能体时代正式到来：定性为60年来最大的行业重置
  • AI投资回报”已有答案”：消除投资者对AI投入产出比的疑虑
  • Vera Rubin架构全面量产：新一代架构已进入量产阶段
  • “物理AI”是下一波增长浪潮：机器人、汽车和工厂将成为现实世界中的智能体
  • 全新CPU架构：专为智能体设计
  • AI基建周期长达数十年：暗示当前仍处早期阶段

来源：英伟达股东会摘要

来源：黄仁勋股东大会最新发声

2.3 字节跳动豆包正式上线专业版收费

6月24日，字节跳动旗下豆包正式推出专业版，基于豆包2.1系列大模型，面向办公开发、数据分析、专业设计等场景。

付费方案

档位 月费 说明
标准版 68元/月（连续包月） 基础AI助手功能
加强版 200元/月 更多高级功能
高级版 500元/月 全量功能解锁

年付最高5088元，免费版基础功能保持不变。豆包2.1为智能体模型，在项目规划、文件处理、工具调用等多步操作能力上有所提升。

行业分析师认为，国内头部通用大模型已跳出单纯免费获客阶段，行业进入”免费普惠+付费增值”双轨商业化深水区。

来源：豆包专业版正式发布

2.4 Ornith-1.0 开源模型家族发布

6月26日，Ornith-1.0 开源模型家族发布，专注 Agentic Coding（智能体编程），覆盖9B到397B全参数规模。基于 gemma4 和 qwen3.5 后训练，采用强化学习联合优化，全系列 MIT 开源协议。

来源：Ornith-1.0 开源模型家族发布

三、科技行业

3.1 高通全面进军AI数据中心

6月24日，高通在纽约投资者日发布数据中心AI芯片战略：

  • Dragonfly产品家族：Dragonfly C1000 CPU，250+核心、5GHz+频率，每瓦性能比竞品高两倍以上
  • 微软Azure部署HBC芯片：采用高通全新高带宽计算芯片架构
  • Meta签多代CPU大单：覆盖多个产品世代的战略合作
  • 收购Modular：约39亿美元全股票交易收购AI软件公司，补齐软件生态短板
  • 数据中心预计2027财年带来数十亿美元收入

受消息影响，高通盘后大涨超13%。

来源：高通全面进军AI数据中心

来源：高通投资者日：一颗CPU、一项内存技术

来源：对标英伟达！高通携全新CPU和大手笔收购

3.2 人形机器人集体降价

宇树科技6月24日宣布双足人形机器人Unitree R1售价由3.99万元下调至2.99万元起，即日起开放现货销售。R1重25千克，配备26个高精度关节，支持语音与图像多模态大模型交互。

来源：2026年人形机器人降价事件

3.3 美光科技财报炸裂

美光科技公布2026财年Q3财报：营收同比增长约346%至414.6亿美元，调整后EPS同比增长超12倍至25.11美元，毛利率84.9%，均超预期。盘后一度大涨超16%。SK海力士宣布计划募资约294.3亿美元发行ADR。

来源：2026年6月25日科技热点新闻-CSDN

3.4 IBM 首度推出亚纳米级芯片技术

IBM发布全球首款亚纳米级芯片技术，采用0.7nm节点与三维纳米堆叠架构，指甲盖大小芯片集成近1000亿个晶体管，性能提升50%，能效提升70%。

来源：IBM Sub-1 Nanometer Chip Technology

3.5 达沃斯论坛：”All in AI”引爆全球关注

6月23日至25日，2026年夏季达沃斯论坛在大连举办，以”规模化创新”为主题。1700余名嘉宾齐聚，AI相关专项论坛超过10场，融合议题场次超30场，场场爆满。

核心看点：全球市场关注焦点从技术理论转向经过市场验证的可商业化AI落地方案；外资持续加码中国AI产业，2025年科技研究和技术服务领域新设外资企业1.4万家、同比增长27.2%。

来源：“All in AI”引爆达沃斯

3.6 其他科技动态

  • Runway Agent 2.0：创建、测试和优化广告视频及营销活动
  • Midjourney V8.2 预览上线：新增草稿模式支持风格探索
  • 链博会首设人工智能专区：升级为”数智科技链”
  • 五部门联合启动工业5G独立专网试点
  • 国产稀释制冷机首台下线：科大国盾量子完成工程化开发
  • 上海企业实现量子计算硬件突破：璇相科技研制百万级原子光镊阵列超表面芯片

来源：Runway Agent 2.0

四、IT职场

4.1 DeepSeek发布招聘信息：七大类岗位全面扩张

6月25日晚，DeepSeek发布招聘信息，涵盖全栈开发/算法、AI核心系统研发、运维、产品、模型数据策略、深度学习研究员、职能部门七大类。与裁员潮形成对比，显示AI核心企业在人才争夺上持续加码。

来源：DeepSeek发布招聘信息

4.2 2026科技业裁员与招聘并存

截至5月底，2026年全球科技行业裁员人数突破10万，甲骨文裁减21,000名员工（降幅13%），明确将部分岗位削减归因于AI。但DeepSeek、字节跳动、商汤等AI核心企业仍在大幅扩张。

来源：2026年科技业大裁员

4.3 OpenAI内部报告：Codex如何改变工作方式

OpenAI观察到其智能体 Codex 已取代 ChatGPT 成为内部主要工作工具，各部门输出token中占比从不足10%飙升至99.8%。非开发者用户增长迅猛，AI智能体正从程序员专用工具向普通职场生产力工具泛化。

来源：How Agents Are Transforming Work - OpenAI

五、金融领域

5.1 央行开展5000亿元MLF操作

央行于6月25日开展5000亿元、期限1年的MLF操作。其中3000亿为到期续作，净投放2000亿元，为连续两个月加量续作。

操作节奏：4月净回笼2000亿，5月净投放1000亿，6月净投放2000亿。

5.2 LPR连续14个月持平

6月22日公布：1年期3.0%，5年期以上3.5%，已连续14个月不变。短期下调概率较低，但6月MLF加量为后续降息打开操作空间。

5.3 AI经济规模持续扩大

ExponentialView报告显示：过去12个月全球AI产业实际营收达1100亿美元，年化运行率超1750亿美元，增速约为移动互联网普及浪潮的3倍。

来源：央行明天放麻辣粉5000亿

来源：State of the AI Economy Report
