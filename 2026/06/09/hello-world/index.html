欢迎来到我的博客！

这是我使用 Hexo + GitHub Pages 搭建的个人博客的第一篇文章。

为什么选择 Hexo？

Hexo 是一个快速、简洁且高效的博客框架，它基于 Node.js，支持 Markdown 写作，拥有丰富的主题和插件生态。

为什么选择 GitHub Pages？

GitHub Pages 提供免费的静态网页托管服务，配合 GitHub 的版本管理，可以方便地管理和部署博客。

博客功能

本博客支持以下功能：

  • 分类系统：按主题对文章进行分类管理
  • 标签系统：使用标签为文章添加多维度索引
  • 归档功能：按时间线浏览所有文章
  • 搜索功能：本地全文搜索
  • 暗色模式：支持明暗主题切换
  • 代码高亮：支持多种编程语言的代码高亮
  • 响应式设计：适配各种设备的屏幕尺寸
